# Guilherme Nunes | Professional Portfolio

![Portfolio Preview](public/profile.png) 
A high-performance personal portfolio website engineered to demonstrate advanced frontend capabilities. Built with **Next.js 14** and **Framer Motion**, featuring a "Glassmorphism" aesthetic and complex state management.

🔗 **Live Demo:** [https://guidonunes.github.io](https://guidonunes.github.io)

## 🛠 Tech Stack

* **Framework:** Next.js 14 (App Router)
* **Language:** TypeScript
* **Styling:** Tailwind CSS + Glassmorphism
* **Animation:** Framer Motion (`AnimatePresence`)
* **Icons:** Lucide React
* **Deployment:** GitHub Pages

## ✨ Key Features

* **🃏 Stacked Card Navigation:** Custom "Card Deck" architecture that manages view states without page reloads.
* **🎨 Glassmorphism UI:** Advanced CSS filters, backdrops, and noise textures for a premium feel.
* **⚡ 60fps Animations:** Hardware-accelerated entrance and layout transitions using Framer Motion.
* **📱 Fully Responsive:** Adaptive layout that shifts from vertical tabs (Desktop) to a bottom navigation bar (Mobile).
* **🌗 Dark/Light Mode:** System-aware theme switching.

## 🚀 Getting Started

1.  **Clone the repository**
    ```bash
    git clone [https://github.com/guidonunes/guidonunes.github.io.git](https://github.com/guidonunes/guidonunes.github.io.git)
    ```

2.  **Install dependencies**
    ```bash
    npm install
    ```

3.  **Run the development server**
    ```bash
    npm run dev
    ```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
